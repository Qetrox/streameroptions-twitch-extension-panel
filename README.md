# Streamer Options – Twitch Extension Panel

This repository contains the Twitch extension panel used by the [Streamer Options platform](https://github.com/Qetrox/streameroptions-expressjs).
The panel allowed viewers to interact with streamers in real-time by redeeming points for in-game effects.

## 🧩 Features

- Displays available modules and their point costs
- Displays top watchtime and points for a streamer

## 🛠 Tech Stack

- HTML/CSS/JS (vanilla + Twitch Extension Helper)
- Hosted as a Twitch panel extension
